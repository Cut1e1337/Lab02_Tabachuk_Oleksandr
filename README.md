## Предметна область і дані

Розвідувальний аналіз характеристик легкових автомобілів ринку США 1970–1982 років. Мета — з'ясувати, що визначає їхню економність. Регресійна модель не будується: дослідження готує дані до майбутньої регресії.

| | |
|---|---|
| Набір даних | **Auto MPG**, R. Quinlan (1993), StatLib / CMU |
| Джерело | UCI Machine Learning Repository — <https://archive.ics.uci.edu/dataset/9/auto+mpg> |
| Прямий URL файлу | <https://archive.ics.uci.edu/ml/machine-learning-databases/auto-mpg/auto-mpg.data> |
| Ліцензія | CC BY 4.0 |
| Обсяг | 398 спостережень × 9 змінних |
| Одиниця спостереження | модель автомобіля певного модельного року |
| **Цільова змінна** | `mpg` — миль на галон (США), неперервна; для інтерпретації також `l_per_100km = 235.215 / mpg` |
| Фактори | маса, об'єм двигуна, потужність, циліндри, розгін, модельний рік, регіон виробника |

### Дослідницькі запитання
1. Який вигляд має розподіл `mpg`, чи є незвичні спостереження?
2. Які характеристики найсильніше пов'язані з `mpg` і чи є зв'язки лінійними?
3. Чи відрізняються авто з США, Європи та Японії за однакової маси?
4. Як змінилася економність у 1970–1982 роках: менші авто чи кращі технології?
5. Наскільки фактори мультиколінеарні?

### Ключові результати
- Маса — найсильніший фактор (ρ Спірмена = −0,88). Зв'язки з `mpg` нелінійні, а з л/100 км майже лінійні.
- «Перевага» японських авто (+10 mpg) здебільшого пояснюється їхньою меншою масою: за однакової ваги різниця становить 2–3 mpg.
- За 1970–1982 роки економність зросла майже вдвічі. Зросла вона і в межах однакових вагових груп, тобто це не лише полегшення авто.
- Маса, об'єм, потужність і циліндри сильно мультиколінеарні (VIF до 20).

## Відтворення

```bash
pip install -r requirements.txt
cd notebooks
jupyter nbconvert --to notebook --execute --inplace EDA.ipynb   # або Run All у VS Code / Jupyter
cd ..
python reports/build_presentation.py
```

Ноутбук читає `data/raw/auto-mpg.data` (якщо файлу немає, завантажує його з URL UCI). Він зберігає очищені дані в `data/processed/`, таблиці в `outputs/tables/`, графіки в `outputs/figures/`. Презентація будується лише з цих збережених результатів, без повторного запуску EDA.

## Обробка даних (коротко)
- 6 пропусків `horsepower` (1,5 %) заповнено медіаною в групі «циліндри × регіон», рядки позначено прапорцем `hp_imputed`.
- Виправлено помилки в назвах марок (`chevroelt`, `toyouta`, `vokswagen`, `maxda`…).
- Викиди (1 за `mpg` — Mazda GLC, 46,6 mpg) є реальними авто й не видалялися.
- Додано метричні одиниці (кг, л, л/100 км) та вагові групи (терцилі маси).
